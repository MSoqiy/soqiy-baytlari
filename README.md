## Imkoniyatlar
- 960 dan ortiq ruboiy, har biri naqshinkor ramkada: yuqorida asl matn, pastda tarjima
- Tarjima tillari: o‘zbek (lotin, arab yozuvi), qoraqalpoq, qozoq, qirg‘iz, turkman, ozarbayjon, turk, tojik, gruzin, rus, ingliz, xitoy, koreys
- Kitobdek 3D varaqlash va qog‘oz shitirlashi
- Tasodifiy, ketma-ket, saralanganlar (♥) va qidiruv rejimlari
- Harf o‘lchami: sozlamalarda yoki ikki barmoq bilan kattalashtirish (ko‘zi xiralar uchun)
- Internetsiz ishlaydi, reklama yo‘q
